Request for Art

A request for art goes out to the pool: here is the hash of a painting, find the prompt that makes it. Every miner starts generating. Each attempt scatters onto the board, landing closer to the center the more it looks like the requested art. Only an exact match reaches the middle.

The request

One machine generates art from a secret prompt and broadcasts only its hash. The painting stays hidden in the center.

The scatter

Miners generate guesses in parallel. Outer ring: nothing in common. Inner rings: one or two words right, so the colors or shapes start to match.

The solve

Only the exact prompt run through the exact model reproduces the hash. That attempt flies to the center and is minted.
