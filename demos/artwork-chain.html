Artwork Chain

Each block on this chain is a painting. A generative model paints it from one verse of Genesis plus the hash of the block before it. Anyone holding the model can repaint every block and confirm the chain; anyone without it can't reproduce a single one.

An interactive sketch of ironchef's 2023 essay “Generative AI Blockchains are Coming.” The model here is a small procedural painter standing in for a billion-parameter image model, so the whole thing runs in your browser.

Minting

The prompt is the next verse. The model's weights, the verse and the previous block hash seed the painting, so every block depends on everything before it.

Verifying

Validators rerun the canonical model on each block. If the painting it produces matches the stored fingerprint, the block is genuine.

Forging

Edit a verse, or mint with the knockoff model, then verify. Without the exact model you can't produce paintings the network accepts.
