Prompt Mining

Proof of Generation, running live. One machine picks a secret prompt, paints it, and broadcasts only the hash of the painting. Twelve miners race to find a prompt that paints the same image. The first to match mints it as an NFT and sets the next puzzle.

An interactive sketch of ironchef's 2023 essay “Generative Blockchains.” Prompts are noun, verb, noun, as in the essay. The model is a small procedural painter standing in for a real image model, so it runs in your browser.

Propose

A machine rolls a random noun, verb and noun, paints it, and publishes only the painting's hash. The prompt stays secret.

Mine

Every miner feeds random prompts into the same model and hashes the result. Work is spent on generation instead of arbitrary puzzles.

The catch

Switch to noisy output. Real models rarely paint the same image twice, so even the right prompt misses the hash. The essay calls this out: as written, it isn't secure.
